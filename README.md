# TOŁDI GRZYBIARZ — V154

Aktualna paczka gry przeglądarkowej **TOŁDI GRZYBIARZ**.

## Uruchomienie na GitHub Pages
1. Rozpakuj archiwum ZIP.
2. Wgraj **zawartość** tego folderu do głównego katalogu repozytorium (root), razem z `index.html`, `game.js`, `style.css` i plikami graficznymi.
3. Zatwierdź zmiany w gałęzi `main`.
4. Otwórz stronę GitHub Pages i odśwież ją. Jeśli przeglądarka trzyma starą wersję, wykonaj twarde odświeżenie lub wyczyść pamięć podręczną.

## Historia zmian
Pełna lista zmian znajduje się w pliku [CHANGELOG.md](CHANGELOG.md).

## Ważne
Nie wgrywaj samego pliku ZIP jako zamiennika plików gry — najpierw go rozpakuj. Zachowaj nazwy plików i strukturę katalogu.
